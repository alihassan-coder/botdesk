# @botdesk/mobile — coming soon

The BotDesk mobile app for iOS and Android, built with Expo (React Native).

**Planned:** chat with your bots, approve or deny actions from a notification, watch a bot's computer
live, and pick up any thread you started on desktop. UI with NativeWind + react-native-reusables
(shadcn-style). Talks to the same API as web and desktop.
